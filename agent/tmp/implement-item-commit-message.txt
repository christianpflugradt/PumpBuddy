refactor(api): modularize backend router and handlers

Extract backend API handler implementations into feature-focused modules
under `backend/src/api/handlers/` and move the transport wiring into
`backend/src/api/router.rs`. The top-level router is now primarily wiring
and middleware composition; handler modules contain the endpoint logic.

Preserves existing API behavior and middleware enforcement. Verified by
running `cargo test --manifest-path backend/Cargo.toml` (all tests pass).

Files changed:
- backend/src/api/router.rs (new)
- backend/src/api/handlers/mod.rs (new)
- backend/src/api/handlers/gyms.rs (new)
- backend/src/api/handlers/training_plans.rs (new)
- backend/src/api/handlers/workouts.rs (new)
- backend/src/api/mod.rs (updated)

No breaking changes.
